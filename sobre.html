Sobre o EcoRota

A origem do projeto, a lógica por trás do sistema e o impacto que buscamos.

O problema que motivou tudo

Muitas pessoas desejam descartar corretamente pilhas, eletrônicos, remédios vencidos e outros resíduos especiais — mas não sabem onde fazer isso. A informação existe, porém está fragmentada: perdida em PDFs da prefeitura, espalhada em sites de fabricantes, ou simplesmente desconhecida.

O EcoRota resolve isso com uma pergunta simples: o que você quer descartar? A partir daí, o sistema exibe apenas os pontos de coleta que aceitam aquele material específico.

Como o sistema funciona

A lógica principal do sistema é baseada em filtragem. Cada ecoponto tem uma lista de materiais aceitos, guardada em um vetor.

// O usuário clica em "Pilhas"
function selecionarCategoria(id) {

  // Se a categoria já estiver ativa, desativa
  if (categoriaAtiva === id) {
    categoriaAtiva = null;
  }

  // Senão, ativa a categoria
  categoriaAtiva = id;

  // Filtro: quais ecopontos aceitam esse material?
  const pontos = ECOPONTOS.filter(ep => ep.materiais.includes(id));

  // Renderiza os resultados na lista lateral
  renderResultados(pontos, id);

  // E renderiza os marcadores no mapa
  renderMarcadores(pontos, id);
}
