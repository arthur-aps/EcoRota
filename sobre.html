Sobre o EcoRota

A origem do projeto, a lógica por trás do sistema e o impacto que buscamos.

O problema que motivou tudo

Muitas pessoas desejam descartar corretamente pilhas, eletrônicos, remédios vencidos e outros resíduos especiais — mas não sabem onde fazer isso. A informação existe, porém está fragmentada: perdida em PDFs da prefeitura, espalhada em sites de fabricantes, ou simplesmente desconhecida.

O EcoRota resolve isso com uma pergunta simples: o que você quer descartar? A partir daí, o sistema exibe apenas os pontos de coleta que aceitam aquele material específico.

Como o sistema funciona

A lógica central é uma estrutura condicional: dependendo do material selecionado pelo usuário, o sistema filtra e exibe apenas os ecopontos relevantes. Em código, isso funciona assim:

// O usuário clica em "Pilhas"
function selecionarCategoria(material) {

  // SE o material for "pilhas"...
  if (material === "pilhas") {
    // ...exibe os pontos A, B e C
    exibirPontos([pontoA, pontoB, pontoC]);

  // SENÃO SE for "oleo"...
  } else if (material === "oleo") {
    exibirPontos([pontoD, pontoE]);

  // SENÃO, qualquer outro material
  } else {
    exibirPontos(filtrarPorMaterial(material));
  }
}

Na prática, o EcoRota usa uma versão um pouco mais complexa desse mesmo princípio: cada ecoponto tem uma lista de materiais aceitos, e o filtro verifica qual ponto contém o material escolhido.
